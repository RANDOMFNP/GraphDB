# Thank you for contributing to GRAPHLIB! To make sure graphlib isnt destroyed we ask that you follow these rules:
* __1__. Use of AI (Artificial Intelligence) is allowed but you must submit with your issue how much was generated with AI and if there are any bugs with the code
* __2__. Files to be submitted are overseen by me to check for quality and production safety to ensure that users will have a worry free time using this product
* __3__. Any feature requests must be submitted via an issue with the title being formatted as [FR] <title> and have an MVP (Minimum Viable Product) for it linked in your forked version of your repository
* __4__. Harassing other people via an issue is NOT ALLOWED
* __5__. To delete a file, 3 people + me will decide via an issue of which all users can comment on
